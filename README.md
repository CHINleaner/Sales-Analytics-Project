# Sales Analytics Dashboard

## Project Overview
This project is an end-to-end Sales Analytics solution built using Excel, SQL Server, and Power BI.  
The project focuses on analyzing sales performance, profit trends, customer segments, and regional performance to generate business insights.

---

## Tools & Technologies Used
- Excel
- SQL Server
- Power BI
- DAX
- Pivot Tables
- Data Cleaning

---

## Project Workflow

### 1. Data Cleaning & Preprocessing
- Cleaned raw sales dataset in Excel
- Removed inconsistencies and formatted data
- Added calculated columns and KPIs

### 2. Excel Analysis
- Built Pivot Tables
- Created KPI cards
- Developed interactive Excel dashboard using charts and slicers

### 3. SQL Analysis
- Imported dataset into SQL Server
- Wrote SQL queries for:
  - Sales analysis
  - Profit analysis
  - Regional performance
  - Category insights
  - Segment analysis

### 4. Power BI Dashboard
- Built interactive Power BI dashboard
- Added KPI cards and slicers
- Performed trend analysis and business insight generation

---

## Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Top Region
